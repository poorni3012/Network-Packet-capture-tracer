Network Packet Capture and Analyzer

Python & Scapy Based Network Traffic Analysis Project

📌 Overview

This project is a Python-based Network Packet Capture and Analysis tool developed using the Scapy library. It captures live network packets and displays important information about network communication.

The project helps in understanding how data flows between source and destination systems and provides practical knowledge about network protocols and packet structures.

🎯 Objective

  • Capture live network traffic packets.
  • Analyze captured packet structures.
  • Identify Source and Destination IP addresses.
  • Detect TCP, UDP and ICMP protocols.
  • Display Source and Destination ports.
  • Analyze packet payloads.
  • Understand basic network data flow.

🛠️ Technologies Used

Python Scapy TCP/IP Network Protocols Packet Analysis

⚡ Features

  • Live network packet capture.
  • Source IP identification.
  • Destination IP identification.
  • TCP, UDP and ICMP protocol detection.
  • Source and Destination port detection.
  • Payload analysis.
  • Detection of binary or encrypted payload data.

🔄 How It Works

Network Traffic ↓ Packet Capture using Scapy ↓ Packet Analysis ↓ IP Identification ↓ Protocol Detection ↓ Port Analysis ↓ Payload Analysis ↓ Display Results

📦 Installation

Install the Scapy library using: 

pip install scapy

▶️ How to Run

Run the Python program using: 

python task1.py

On Windows, administrator privileges may be required for network packet capturing.
